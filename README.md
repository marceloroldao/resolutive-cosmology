# Resolutive Cosmology

Private scientific-computing repository for developing, testing, and auditing Resolutive Cosmology against the standard ΛCDM model.

## Scientific scope

The project will implement a reproducible pipeline for:

- cosmic expansion and redshift;
- background evolution H(z);
- cosmological distances;
- Type Ia supernovae;
- baryon acoustic oscillations (BAO);
- CMB distance priors;
- joint statistical comparison with ΛCDM.

## Current status

The repository is in its initial infrastructure phase (`v0.1.0-dev`). The physical equations, datasets, priors, and validation protocol will be added incrementally and reviewed through pull requests.
