# Resolutive Cosmology

Scientific-computing repository for developing, testing, and auditing Resolutive Cosmology against established cosmological baselines, including ΛCDM.

## Scientific scope

The project develops reproducible pipelines for:

- cosmic expansion and redshift;
- background evolution H(z);
- cosmological distances;
- Type Ia supernovae;
- baryon acoustic oscillations (BAO);
- CMB distance priors;
- joint statistical comparison with ΛCDM and other appropriate baselines.

## Relationship to Resolutive Science

`resolutive-science` is the normative source of truth for shared Resolutive Science terminology, notation, scientific status labels, and mathematical specifications.

This repository is an implementation and experimental workspace for the cosmology research line. It does not define an independent competing version of RCMS or RSMS.

- Resolutive Science repository baseline: `v0.1.1`
- RSMS compatibility: `1.0-rc.1` — candidate compatibility, subject to re-audit when RSMS 1.0 becomes stable
- Project governance baseline: `RSPS 1.0-draft`

Any local deviation from the normative specification must be documented explicitly.

## Current status

**Maturity:** alpha / development research line.

The repository is publicly visible for scientific audit and reproducibility. Public visibility does not imply that the underlying physical hypotheses are experimentally validated or that the project is a stable scientific release.

Physical equations, datasets, priors, validation protocols and software changes are developed incrementally and should be evaluated through reproducible tests and documented review.

## Reproducibility and claim discipline

Results must distinguish mathematical consistency, software verification, numerical performance, observational agreement and independent scientific validation. Negative and inconclusive outcomes should be preserved when scientifically relevant.
