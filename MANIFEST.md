# Resolutive Cosmology Manifest

## Mission
Develop a mathematically explicit, computationally reproducible, and scientifically falsifiable implementation of Resolutive Cosmology.

## Method
The project follows a traceable chain:

**Hypothesis → equation → implementation → test → observational comparison → conclusion**

## Principles
- Mathematics precedes interpretation.
- Code must expose assumptions and units.
- Observational comparisons must be symmetric between models.
- Data take precedence over expectations.
- Negative and null results remain part of the scientific record.
- Reproducibility is a requirement, not an optional feature.

## Scientific boundary
The repository implements and tests a research hypothesis. Until supported by independent evidence, Resolutive Cosmology must not be described as established physics.
